About Bid Studio

Why we built it and how it works.

Funding is won on the criteria

Most unsuccessful applications are not badly written. They are written to the wrong target. Funders publish criteria and weightings, and reviewers score against them. Bid Studio keeps drafting, scoring and review tied to those criteria from the first paragraph.

Grants first, tenders alongside

Grant and funding proposals are the primary product. Because many teams also answer public tenders, the same workspace supports clarification questions, pricing narratives, social value statements and debriefs.

Open and extensible

Bid Studio is a Python and FastAPI application with a documented JSON API (API docs) and an MIT licence. It runs on SQLite locally and PostgreSQL in production.
