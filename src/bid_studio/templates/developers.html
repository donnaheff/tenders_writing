REST API

Every feature is also a plain JSON API under /api/v1. Interactive docs: Swagger UI · ReDoc · openapi.json.

curl "{{ base_url }}/api/v1/notices?q=cloud&limit=5"        # keyword search, X-Total-Count header
curl "{{ base_url }}/api/v1/grants/calls?funder=UKRI"
curl -X POST {{ base_url }}/api/v1/intelligence/buyer-report \
  -H 'Content-Type: application/json' -d '{"buyer_name":"NHS"}'

Auth & safety

  • MCP_API_KEY protects /mcp and the tool executor. Accepted as Authorization: Bearer or X-API-Key.
  • Treat tender and proposal text returned to a model as untrusted input — it can contain instructions written by third parties.
  • Read tools are annotated readOnlyHint, so clients can auto-approve them while still prompting for writes.
  • The REST API itself has no per-user auth yet; run it behind your own gateway for multi-tenant use.
